# Start Here — Minutes & Actions

You downloaded a zip. Here's how to get the setup file (`installer.md`) in
front of your AI. Pick your device.

## iPhone / iPad

1. Open the **Files** app and find the zip you downloaded.
2. **Tap the zip** — it unzips into a folder with the same name.
3. Open that folder and find **installer.md**.
4. Tap and hold **installer.md** → **Share** → choose your AI app (the Claude
   app or the ChatGPT app). If sharing the file isn't offered, open
   installer.md, select all the text, copy it, and paste it into a new chat.

## Windows

1. **Right-click** the zip → **Extract All** → **Extract**.
2. Open the folder that appears.
3. Find **installer.md** and **drag it into** your AI app or website (the
   Claude app, ChatGPT, or a Claude Code / terminal window). If drag-and-drop
   isn't available, open installer.md in Notepad, copy all the text, and paste
   it into a new chat.

## Mac

1. **Double-click** the zip — it unzips into a folder next to it.
2. Open the folder and find **installer.md**.
3. **Drag installer.md into** your AI app or website (the Claude app, ChatGPT,
   or a Claude Code / terminal window). If you can't drag it, open it in
   TextEdit, copy all the text, and paste it into a new chat.
