# voice

How the user writes, so drafted follow-up emails sound like them instead of
like a generic AI.

- `your-voice.md` - the single source of truth for greeting, sign-off and
  signing name, formal-or-relaxed tone, and length. The installer's voice
  interview fills it in, and the user can edit it any time.

`draft-followups.md` reads this before writing any email. Unanswered fields
are still placeholders in curly braces.
