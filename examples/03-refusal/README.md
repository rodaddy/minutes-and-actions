# 03 - refusal

The kit saying no. A thin status-update meeting trips the trackability gate
(fewer than two trackable things across owned actions, decisions, and loose
ends), so the kit stops and asks before writing anything.

`01-INPUT-thin-meeting.md` is the input. `02-OUTPUT-the-stop.md` is the stop
message and both ways it can go: the user answers the question, or says "go
ahead" and gets minutes with every gap listed in the Parking Lot.
