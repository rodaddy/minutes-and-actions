# OUTPUT — the ledger, after run one

This is `skills/minutes/ledger/action-items.md` after the first meeting. Five
rows, every one of them at Times Raised `1`, because nothing has been
re-promised yet. The file starts empty and grows from here; it is never
rewritten.

```

| Unassigned | Take the F-350 in for brake work | Not set | Open | Monday Ops | 2026-04-07 | 1 | 2026-04-07 |
```

Two columns do the work later:

- **Times Raised** goes up by one every time a meeting re-promises the same
  commitment. It never spawns a duplicate row.
- **Last Raised** is when it last came up, so a thing can be old and still
  actively discussed, or old and quietly forgotten. Those are different
  problems and the report tells them apart.
