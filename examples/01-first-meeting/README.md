# 01 - first meeting

Day one, run one: a messy phone voice memo goes in and the kit hands back
minutes in the fixed format, a fresh ledger, an honestly-empty aging report,
and a follow-up draft.

Read the files in numbered order. `01-INPUT-what-was-pasted.md` is what the
user pasted; the `02`-`05` OUTPUT files are everything that came back. Note
the missing date flagged rather than invented, and the one action marked
Unassigned. Vitale Landscaping & Masonry and everyone in it are invented.
